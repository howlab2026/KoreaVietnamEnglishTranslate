## 4. 파일별 상세 분석

### 4.1 `server.js` (백엔드 서버, 77줄)

#### 주요 기능
1. **Gemini Ephemeral Auth Token 발급 (`GET /api/token`)**:
   - 클라이언트에서 Gemini Live API로 직접 WebSocket 통신을 수행할 수 있도록 임시 토큰(ephemeral token)을 발급합니다.
   - 단일 발화에 대해 2개 언어로 동시 번역하기 위해 `ai.authTokens.create`를 병렬(`Promise.all`)로 2회 호출하여 `tokenA`, `tokenB`를 발급합니다.
   - 토큰 제약조건:
     - `uses: 1` (1회용 세션 연결)
     - `expireTime`: 현재 시간 기준 30분 만료 (`Date.now() + 30 * 60 * 1000`)
     - `liveConnectConstraints.model`: `gemini-3.5-live-translate-preview` 모델 전용
2. **캐시 제어 (Cache-Control)**:
   - 클라이언트 브라우저 캐시로 인한 구버전 스크립트 로딩을 방지하기 위해 `no-store, no-cache, must-revalidate` 헤더를 전역 미들웨어로 강제 주입합니다.
   - 정적 파일 서빙(`express.static`)에서도 `etag: false, maxAge: 0`을 지정했습니다.
3. **정적 파일 서빙 및 SPA Fallback**:
   - `public` 폴더를 루트 정적 경로로 서빙합니다.
   - Express 5 문법에 맞추어 `app.get("*splat", ...)` 와일드카드 라우트로 `index.html`을 fallback 반환합니다.

#### 특이점 및 안정성
- API 키 부재 시 콘솔 경고(`WARNING: GEMINI_API_KEY is not set.`)를 띄우며, 토큰 발급 실패 시 500 상태코드와 에러 상세를 JSON으로 응답합니다.

## 6. 발견된 문제점 및 결함 분석 (Critical Findings)

### 🚨 [Critical] `public/app.js` 파일 누락
- `index.html` 149행에서 `<script type="module" src="/app.js?v=1.0"></script>`를 불러오고 있으나, **실제 파일이 존재하지 않습니다.**
- 이로 인해 현재 상태에서는:
  - 언어 모드 변경 클릭 이벤트 미작동
  - 마이크 장치 목록 가져오기 및 음량 시각화 미작동
  - 번역 시작/중지 및 Gemini API 통신 불가
  - 폰트 슬라이더, 전체화면, 히스토리 내보내기 등 UI 전반 인터랙션 미작동

### ⚠️ [Security] API 엔드포인트 보안
- `server.js`의 `/api/token`은 인증 절차(인증 토큰, 세션, Rate Limiting 등) 없이 누구나 무제한으로 호출할 수 있어, 서비스 공개 시 Gemini API 할당량 소진 우려가 있습니다.

   - 시스템 프롬프트(System Instruction) 주입:
     - Session A: "You are a professional simultaneous interpreter. Translate [Source] to [Target A] in real time."
     - Session B: "You are a professional simultaneous interpreter. Translate [Source] to [Target B] in real time."
   - 수신된 오디오/텍스트 델타를 DOM(`#transAText`, `#transBText`)에 렌더링.
   - 통역 종료 시 히스토리 배열에 저장 및 CSV/TXT 다운로드 기능 연동.

2. **백엔드 보호 강화**:
   - `express-rate-limit` 등을 도입하여 토큰 생성 요청 횟수 제한.
   - CORS 허용 오리진 제한 설정.

3. **네트워크 예외 처리**:
   - 30분 토큰 만료 전 자동 갱신(Refresh) 매커니즘 구현.
